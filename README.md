# Trilhas do Paraná

Guia de trilhas do Paraná para quem quer sair da cidade e caminhar com segurança. A página única apresenta uma lista de trilhas (com cidade, nível de dificuldade, distância, duração e altitude), que poderá ser filtrada por dificuldade, e uma segunda lista chamada "Antes de sair", com os itens essenciais para levar na mochila. Projeto desenvolvido como Trabalho de Conclusão de Disciplina (TCD) de Front-End, usando React, TypeScript e Tailwind CSS.
